วิธีนำไปใช้งานจริง

      
    
        
  1. Capture ส่วนภาพด้านบนเป็น PNG/JPEG ขนาด 2500×1686 (ไม่เกิน 1 MB) หรือออกแบบใหม่ใน Figma ตามสัดส่วนนี้
    2. 
        
  2. สร้าง LIFF app ใน LINE Developers Console สำหรับหน้า ร้องเรียน / จองคิว / ติดตามสถานะ แล้วแทนที่ LIFF_ID_*
    3. 
        
  3. POST https://api.line.me/v2/bot/richmenu ด้วย JSON ด้านบน → อัปโหลดรูปที่ /richmenu/{id}/content → ตั้งเป็นค่าเริ่มต้นด้วย /user/all/richmenu/{id}
    4. 
        
  4. ปุ่ม postback (ข่าว / ภาษี / ติดต่อ) ให้ webhook ตอบกลับเป็น Flex Message ตามตัวอย่างในหน้าแชท
    5. 
        
  5. หรือใช้ LINE Official Account Manager → Rich menus → Template “Large 6 ช่อง” แล้วกำหนด action เอง (ไม่ต้องเขียนโค้ด)
    6.
